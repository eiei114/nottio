# nottioは付箋の絵から、一つの折り返しマークへ

旧アイコンは黄色い付箋、矢印、接続先の四角を並べていた。ユーザーの「もっとモダンに」という指摘を受け、今回は考えをつなぐ動きを一つの青紫のマークにまとめた。白に近い台座と、折り重なる二つの面で、nottioの頭文字も連想できる形にした。

## 公式素材4件で、形・色・余白を比較した

2026年10月14日時点で公開されている公式ブランドページと画像を確認した。下表の見た目は画像の観察、採用点はnottio向けの判断である。各アイコンが最近リリースされたとは断定していない。

| アプリ | 確認した見た目 | nottioに取り入れる点 |
| --- | --- | --- |
| [Linear](https://linear.app/brand) | 暗い地に大きな白い円形マーク。斜めの切れ目と控えめな陰影がある | 細かな機能説明を減らし、大きな輪郭と余白で見分けやすくする |
| [Raycast](https://www.raycast.com/press) | 公式配布画像は暗い台座、赤い縁、小さなマークと文字を使っている | アクセント色を絞る。強い縁取りや文字は今回は使わない |
| [Craft](https://www.craft.do/brand) | 明るい台座に、四つの色付きパーツをまとめたマーク。暗い版も配布している | 明るい台座と、まとまりのある幾何形状を使う |
| [Obsidian](https://obsidian.md/brand) | 紫の複数の面で構成した岩のマーク。面ごとの明暗で奥行きがある | 近い色相と控えめな陰影で折り返しを表す。岩の形は模倣しない |

Linearはブランド素材の組み込みや無断改変を禁じている。Obsidianもロゴの改変を禁じ、商用利用には連絡を求めている。ここでは形や余白の考え方だけを参考にし、他社の画像を製品には使っていない。比較用のダウンロードは一時フォルダだけに置いた。

## Windowsで小さく表示しても、形が残るようにした

[Microsoftのアイコン設計ガイド](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-design)は、単純な形、少ない角、識別しやすい輪郭を勧めている。比喩は二つまでとし、グラデーションや色の処理も控えめにする方針だ。これはWindows向けの指針であり、全アプリが同じ様式を使うという意味ではない。

nottioでは、付箋・矢印・接続先を個別に描く構成をやめた。青から青紫へ移る幅広い折り返しと、白に近い台座を組み合わせる。文字や飾りは入れず、16・24・32・48・64・96pxのプレビューを明暗両方の背景で確認した。小さな表示では立体感より、二本の面と斜めの接続部分が読めることを優先した。

生成画像の外周には透過のざらつきが残ったため、実際の台座だけを切り出し、計算で描いた滑らかな角丸マスクを適用した。元画像と変換スクリプトは残している。

## 本体とピン留めの両方を、新しい画像へ切り替える

アプリ本体は従来どおり、10解像度のICOをWindowsリソース1番に埋め込む。タスクバーのピンは、画像のSHA-256を含む別ファイル名のICOを参照する。同じファイル名に残る旧アイコンのキャッシュを避けるための変更だ。

今回はショートカットの更新だけでは旧画像が残ったため、Windows標準の再描画通知も送った。ほかのアイコンも再描画される可能性はあるが、関連付けの設定、キャッシュファイル、ピン留め、アプリのグループ設定は変更しない。Explorerの再起動も不要だった。

見た目の採否はユーザーの好みに依存する。今回の比較は4製品に限られ、人気や好感度を測った調査ではない。色や抽象度の再調整が必要なら、この形をたたき台にする。
